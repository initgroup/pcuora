Oracle Machine Learning(OML)은 데이터베이스의 데이터를 이용해 패턴을 학습하고 예측하는 기능입니다. 이 수업은 OML for SQL을 사용합니다. Python은 웹 요청을 받고 PL/SQL을 호출하며, 실제 모델 학습과 예측은 Oracle에서 수행합니다.

DBMS_DATA_MINING은 모델을 만들고 관리하는 PL/SQL 패키지입니다. PREDICTION, PREDICTION_SET 같은 SQL 함수로 학습된 모델을 적용합니다. OML for Python의 oml 패키지와 Python 접속 드라이버 oracledb는 서로 다른 도구입니다. 이번 실습에는 OML for Python 설치가 필요하지 않습니다.

상관계수 계산은 기술통계입니다. CORR는 DBMS_DATA_MINING의 학습모델 생성 함수가 아닙니다. 연관규칙 또한 지도 분류모델과 다른 목적을 가집니다.

학습과 예측은 다른 작업입니다.

01문제 정의무엇을, 언제 예측할까?
02데이터 준비관측값 X와 정답 y
03학습·평가규칙을 찾고 검증하기
04새 입력 예측모르는 정답 추정하기

학습은 정답을 이미 아는 과거 사례에서 일반적인 패턴을 찾는 과정입니다. 예측은 정답을 아직 모르는 새 사례에 그 패턴을 적용하는 과정입니다. 모델은 정답 목록을 조회하는 표가 아닙니다. 실제로 사용 가능한 입력만으로 판단해야 합니다.

평가에서는 학습에 참여하지 않은 데이터의 정답과 예측을 비교합니다. 좋은 학습 점수만으로 새 고객에게도 잘 작동한다고 주장할 수는 없습니다.
