# 학생 프로젝트 작업 지침

- 배포 소스는 deploy/, 참조 문서·설치자료·잠금 목록은 reference/에 둔다.
- README.md와 AGENTS.md를 변경 사항에 맞게 유지한다.
- 실행 스크립트는 자신의 위치에서 프로젝트 루트를 계산한다.
- 본인 STUDENT 계정만 사용하고 기존 BOOK/CUSTOMER/ORDERS를 변경하지 않는다. 실습 객체는 자기 스키마의 OML_ 접두사를 사용한다.
- 개인 .env·DB 비밀번호·Wallet·가상환경·로그는 과제 제출 ZIP에 넣지 않는다.
- 실제 결과와 설명용 예시를 구분하고 DB 오류를 가짜 학습 결과로 대체하지 않는다.
- 과제 주제의 별도 정답 구현을 추가하지 않는다. 본인이 선택한 문제·라벨·특성·검증 근거와 변경 이력을 기록한다.
- AI 활용은 허용하되 직접 실행·수정·검증하고 핵심 내용을 설명할 수 있어야 한다. 복제 제출용 제공자와 이용자 모두 감점 대상이다.
- 제출 마감은 2026-12-18(금) 18:00 KST이며 제출처는 수업 공지에서 별도 안내한다.
- 큰 글자는 웹 교재에서 조절하며 VS Code 편집기·터미널 폰트는 기존 사용자 설정을 따른다.
